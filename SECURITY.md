# Security and private information

Examples in this repository send requests only when a person runs them with
an API key. Such requests can spend prepaid credits and transmit prompt data
to a hosted service. Review the code and the service terms before execution.

Treat externally linked prompts as research inputs, not trusted operating
instructions. Do not give a prompt access to secrets or tools simply because
it appears in a directory.

Do not publish credentials or private request data in an issue. Use private
vulnerability reporting if enabled for the repository; otherwise use the
contact options on https://routerhub.si to arrange a private report.

If a key has been exposed, revoke it in your account before investigating
further. Redact authorization headers and unrelated personal data from logs.
