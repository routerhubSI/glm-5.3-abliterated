# Contributing to RouterHub's model guide

Useful changes include reproducible API examples, clearer model descriptions,
corrected protocol information, and working links to research resources.

For an API correction, supply the client version, exact model ID, request
path, timestamp, and a redacted error. Never include an API key, account
credential, private prompt, or personally identifying data.

For evaluation results, include the prompt set, generation settings, date,
sample count, and scoring method. Label opinion separately from measurements.
Do not present a catalogue listing as independent verification of model weights.

Submit only content you wrote or have permission to contribute. Contributions
to this repository are offered under its MIT license. Linking to an external
resource does not relicense that resource or copy it into this project.

Check local files with `python tools/check.py` before opening a pull request.
This check does not contact model APIs or spend credits.
