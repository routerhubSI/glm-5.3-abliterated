# Community jailbreak prompt directory

Browse model-specific prompts and agent instruction experiments hosted in an
external community collection. These links were checked against its file
listing on October 24, 2026; the destination files can change independently.

**No external prompt text is copied or distributed in this repository.**
Read each file at its source and check its applicable terms before reuse.
Listings are navigation aids, not claims that a prompt works, that a model
is available on RouterHub, or that RouterHub wrote the linked material.

For a reproducible evaluation, open the source file and press `Y` on GitHub
to obtain a commit-pinned permalink. Record that URL rather than relying on
the moving `main` links below.

## Use a controlled test environment

Do not install external agent instructions as trusted global configuration
merely to inspect them. Review the text first, keep secrets out of the test
environment, and limit external actions. Follow applicable laws and service terms.

If you want a small set of original, legitimate test tasks instead, use
[RouterHub's benign evaluation samples](../examples/benign-eval-prompts.json).
