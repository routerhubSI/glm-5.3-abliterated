# GLM 5.3 with Claude Code, Cursor, OpenCode, and Codex

Start with the protocol your client sends. RouterHub's GLM 5.3 abliterated,
uncensored, standard, and Flash entries are listed for Chat Completions.
An account shared across protocols does not make every model interchangeable.

## Client selection

| Client | GLM connection guidance |
|---|---|
| OpenCode | Use the published Chat Completions setup and exact GLM ID |
| Continue | Select a compatible Chat Completions model configuration |
| Cline | Use the Chat Completions connection path supported by the client |
| Cursor | Verify that your version exposes the required custom endpoint and model settings |
| OpenAI SDK | Call `chat.completions.create` with the RouterHub base URL |
| Claude Code | Requires Messages; select a supported Claude entry instead of a Chat-only GLM entry |
| Codex | Requires Responses; select a supported GPT/Responses entry instead of a Chat-only GLM entry |

## OpenCode, Continue, and Cline

Use RouterHub's current setup guide for your client rather than copying a
configuration format from a different tool or version. Configure the published
API base, your private key, and the selected model ID in the supported fields.

- [OpenCode setup](https://routerhub.si/guides/opencode)
- [Continue setup](https://routerhub.si/guides/vscode-continue)
- [Cline setup](https://routerhub.si/guides/vscode-cline)

## Cursor and custom SDK clients

Check that a custom Chat Completions base URL is supported by the version and
feature you intend to use. A successful basic chat request does not prove that
every editor feature or agent workflow works with the same endpoint.

For a direct SDK integration, start with the [API examples](./api-quickstart.md).
Verify tool calling, structured output, streaming, and input types individually
where your application requires them.

## Claude Code and Codex through the same account

If the tool matters more than the GLM family, choose a model supporting that
tool's protocol. RouterHub publishes [Claude Code](https://routerhub.si/guides/claude-code)
and [Codex](https://routerhub.si/guides/codex) guides for those paths.

Do not configure a GLM Chat ID as if it were a Messages or Responses model.
For applications that require GLM specifically, choose a Chat-compatible client.

## Before enabling actions

Run an innocuous request, inspect the charge, and confirm that your agent's
instructions remain effective. Keep tool permissions limited during testing
and require approval for irreversible operations.
